# **Q: On a server, the chunks are not loaded when no players are online?**
**Q: On a server, the chunks are not loaded when no players are online?**

Short answer: you must enable offline force loading in the ftbchunks server config.

* Go to your world folder, then open the *serverconfig* folder.
* Find and open the *ftbchunks-world.snbt* file with a text editor.
* Look for the setting *force_load_mode*.
* Change its value to *always* (instead of *default* or *never*).
* Save the file and restart the server so the change takes effect.
