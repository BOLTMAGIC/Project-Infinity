# **Q: How do I use PackagedAuto for Extended Crafting / Draconic Evolution / Re-Avaritia?**
**Q: How do I use PackagedAuto for Extended Crafting / Draconic Evolution / Re-Avaritia?**

Short answer: Treat PackagedAuto like AE2 patterns – encode package recipes, then feed them to the correct Package Crafter via an ME Packaging Provider.

* You will need:
  * ME Packaging Provider
  * The Package Crafter you want:
    * Fusion Package Crafter for Draconic Evolution
    * Advanced / Elite / Ultimate Package Crafter for Extended Crafting
    * (and the appropriate crafter for Re-Avaritia)
  * Package Recipe Encoder
  * Package Recipe Holder

* Basics (think of them as AE2 pattern tools):
  * The Package Recipe Encoder is basically your Pattern Encoding Terminal.
  * The Package Recipe Holder is basically your Blank Pattern.

* Making package recipes:
  * Put a Package Recipe Holder in the Package Recipe Encoder.
  * On the right side, select the correct Recipe Type.
  * Make the pattern:
    * Use JEI’s “+” button when looking at a recipe to fill the grid.
    * You can put up to 20 recipes in one holder – use the empty boxes at the top to switch slots.
  * In the top left, click “Save all recipes to holder”.

* Connecting to AE2:
  * Place the appropriate Package Crafter wherever you want it.
  * Place the ME Packaging Provider next to the Package Crafter.
  * Connect the Packaging Provider to your AE2 network.
  * Put your Package Recipe Holder into the ME Packaging Provider.
  * You should now see the packaged recipes available to craft in your AE2 system.

* Important notes:
  * Ender / Flux Crafting still needs the appropriate blocks around the Package Crafter.
  * Combination Crafting still needs the marked pedestals in place.
  * Fusion Crafting still needs the marked Crafting Injectors.
  * In other words: You still need the same multiblock setups as for manual crafting – PackagedAuto just automates the inputs.
