# **Q: How to automate JDT Goo spreading?**
**Q: How to automate JDT Goo spreading?**

Short answer: Use separate AE2 subnets with formation/annihilation planes, a filtered provider, and make sure top and bottom never directly connect.

![jdt_goo_automation](/photos/jdt_goo_automation.png)

Important notes:
* Use filtered import on the provider:
  * Use the filtered import mode on the provider (5th option from the top).
  * This way, the planes only break finished products, without needing manual filtering.
  * This option is only available on advanced (extended) providers.


* Provider and interface placement:
  * Point the provider toward the interface so they do not auto-connect on the same side.
  * The interface can be the flat version if you prefer.


* Separate subnets with Quartz Fibers:
  * Use Quartz Fibers so each plane sits on its own subnet.
  * Do not connect these subnets directly to the main network.
  * Do not connect the formation planes’ subnet directly to the annihilation planes’ subnet.


* Network layout:
  * All annihilation planes must be on the side connected (through their subnet) to the Storage Bus.
  * All formation planes must be on the side connected (through their subnet) to the Interface.
  * There must be no direct connection from the top (formation planes) to the bottom (annihilation planes), and no direct connection from these subnets to the main AE2 network.


* Scaling and multiple goos:
  * You can extend the setup to use multiple formation and annihilation planes.
  * You can also run multiple kinds of goo at once.
  * The only strict rule is:
    * All annihilation planes feed the Storage Bus.
    * All formation planes feed from the Interface.
    * No direct cross‑connection between those two sides.


* Pattern settings:
  * JDT ores and coals drop 3 or 4 items when broken.
  * For reliable autocrafting, set your patterns to produce 3 items.

* Extra tip:
  * This same setup also works for automating the Botania Pure Daisy.
